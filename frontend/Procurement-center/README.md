# Procurement center

Owns the operator HTML entry, routes, assets, CSS/Tailwind entries, and the
operator-only procurement stage editor in `src/pages/Stages.jsx`. Reusable
management, reports, settings, state, and UI come from `@shared`.

Install dependencies from `frontend` using `npm ci`, then run `npm run dev`.
Open `/Procurement-center/index.html` or choose Procurement Center at login.
Existing operator URLs remain `/operator/*`.
See [the frontend guide](../README.md) for the complete structure.
