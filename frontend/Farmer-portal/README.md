# Farmer portal

Owns farmer HTML, booking/tracking/history screens, the calendar component, assets,
and CSS/Tailwind entries. Shared profile, notifications, support, state, and UI
are imported from `@shared`. The old mobile placeholder is preserved in `mobile`.

Install dependencies from `frontend` using `npm ci`, then run `npm run dev`.
Open `/Farmer-portal/index.html` or choose Farmer on the shared login page.
See [the frontend guide](../README.md) for the complete structure and commands.
